# medicloud-1.0.0

MediCloud — Telehealth SaaS one-page landing template (Tailwind + Bootstrap + Vite).

> Template source in `medicloud-1.0.0/` ([Demo](https://themewagon.github.io/medicloud/)).

## Getting Started
```bash
cd medicloud-1.0.0
npm install
npm run dev     # Vite dev server
npm run build   # production to dist/
npm run preview
```

## Tech
- Vite 6, Bootstrap 5, Sass, GSAP, Tabler Icons
